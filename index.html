AI / ML// Amazon Homepage & Navigation

Personalization pipeline for mobile navigation

The mobile navigation tabs millions of customers see are personalized by ML models — and those models are only as good as their data. I built the pipeline that feeds them, end to end.

Daily clickstream → ETL processing → ML training datasets → model → real-time Datastore → mobile nav tabs

How it works

  • Daily clickstream ingestion — customer interaction data is processed every day into training-ready datasets the personalization models learn from.
  • Dual-purpose output — the same pipeline powers offline AI/ML model training and real-time Datastore serving, so the models and the live experience never drift apart.
  • Impact measurement built in — instrumentation tracks personalization impact across North America, closing the loop between model changes and customer behavior.

How it's used

  • Serves personalized mobile navigation tabs in real time to customers across North America.
  • ML teams train against fresh pipeline output daily; experiment results feed back to guide the next model iteration.

// Amazon Homepage & Navigation

Self-service ranking debugger

When ML models rank content, someone has to be able to explain why. Before this tool, every question about homepage ranking meant a developer manually running scripts against production systems — I architected a platform that turned that into a self-service web experience.

React UI → API Gateway → Lambda → SNS/SQS async jobs → Glue → DynamoDB → results + audit log

How it's built

  • Async job processing — long-running ranking analyses are queued via SNS/SQS and processed by Lambda + Glue, so the UI stays responsive while heavy investigations run in the background.
  • Access control & audit logging — every query is permission-checked and recorded, making investigations safe to open beyond the core team.
  • Real-time content results — a data-driven interface surfaces live ranking output so users see exactly what customers see.

How it's used

  • Engineers, stakeholders, and partner teams self-serve ranking analysis without needing infrastructure access — what used to be a developer ticket is now a few clicks.
  • Teams use it for launch validations, verifying personalization behavior before features ship to the homepage.
