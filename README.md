# Apnav Poptani — Portfolio

Personal portfolio site. Static HTML/CSS/JS, no build step.

## Contents

- `index.html` — the site (single file, all styles and scripts inline)
- `Apnav-Poptani-Resume.pdf` — resume, linked from the nav and contact section

## Deploy to GitHub Pages

1. Create a public repo named `<your-username>.github.io` at https://github.com/new
2. Push this folder's contents to the repo root:

   ```bash
   git init
   git add .
   git commit -m "Portfolio site"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
   git push -u origin main
   ```

3. Live at `https://<your-username>.github.io` within a couple of minutes.

To update the resume later, replace `Apnav-Poptani-Resume.pdf` (keep the same filename) and push.
